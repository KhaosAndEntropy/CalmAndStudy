# Transparência de forks e derivados

O projeto permite reutilização nos limites de cada licença. A página **Forks e derivados** do aplicativo separa os forks que o GitHub reconhece dos projetos independentes enviados para revisão.

## O que cada registro significa

- **Fork no GitHub:** a relação de repositório aparece na rede de forks do GitHub. Isso não indica parceria, aprovação ou endosso.
- **Derivado independente:** entrada sugerida em uma solicitação pública e incluída somente após revisão humana de informações acessíveis, como endereço, origem declarada, créditos, licença informada e alterações descritas.
- **Sem registro:** significa apenas que o projeto não foi incluído nesta lista. A lista é voluntária, não exaustiva, e não determina se uma cópia é permitida ou irregular.

As fichas devem registrar somente fatos conferíveis e a data da revisão. Não publicamos acusações, dados pessoais ou alegações não verificadas. Uma solicitação não garante inclusão; uma ficha pode ser corrigida ou retirada se ficar desatualizada.
