# Imagens dos artigos

Os 79 artigos do catálogo atual têm imagens próprias geradas por IA em estilo fotográfico editorial, em `apps/web/public/images/topics/`, nomeadas pelo identificador do artigo. Os arquivos são servidos como conteúdo estático: visualizar uma imagem não faz chamadas a serviços de IA nem gera custo por acesso.

Mesmo com aparência realista, as imagens são representações artificiais. Não documentam acontecimentos nem servem como evidência de afirmações históricas ou científicas. A página informa isso em uma legenda acessível. Se um arquivo não existir ou falhar, o componente mantém uma alternativa vetorial local.

## Capas das trilhas

As trilhas usam imagens de aparência fotográfica geradas por IA em `apps/web/public/images/trails/`, também nomeadas pelo identificador (`<id-da-trilha>.jpg`). Elas são ilustrações editoriais, não registros históricos ou evidências científicas. `TrailArtwork` mostra uma alternativa local se uma imagem falhar.

## Capas dos tutoriais

Os 12 tutoriais usam imagens fotográficas geradas por IA em `apps/web/public/images/tutorials/`, nomeadas pelo identificador (`<id-do-tutorial>.jpg`). São imagens ilustrativas, não registros de pesquisas ou experimentos. `TutorialArtwork` mantém uma ilustração de reserva local se o arquivo não carregar.
