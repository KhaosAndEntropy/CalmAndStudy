# Decisiones y evolución del proyecto

Registro por separado las decisiones de producto que tomé y las recomendaciones técnicas empleadas para implementarlas. Las fechas son fases aproximadas reconstruidas a partir del proyecto; no son fechas de lanzamiento público.

| Periodo         | Decisión o fase                                                                                                                                                                                         |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 10 nov. 2026    | Empecé con artículos breves de curiosidades, selección de temas, descubrimiento aleatorio, rutas de aprendizaje, imágenes y referencias.                                                                |
| 10–11 nov. 2026 | Amplié el catálogo y añadí relaciones entre temas, tutoriales, ejercicios, sugerencias de lectura y búsqueda de fuentes públicas con criterios explícitos.                                              |
| 11–12 nov. 2026 | Consolidé la PWA adaptable, accesibilidad, preferencias visuales, herramientas de lectura, progreso, participación y navegación.                                                                        |
| 12–13 nov. 2026 | Reforcé la API, validaciones, D1, privacidad, límites de solicitudes, CI, análisis estático y revisión pasiva. Elegí el despliegue integrado GitHub–Cloudflare tras las comprobaciones.                 |
| 13–14 nov. 2026 | Elegí MIT para el código y CC BY 4.0 para textos originales, mantuve el proyecto gratuito, abrí contribuciones y definí dos modos de estudio con criterios editoriales comunes y atención al bienestar. |
| 15 nov. 2026    | Inicié el cambio de marca a Calm & Study y la migración del repositorio, con documentación en portugués, inglés y español.                                                                              |

El nombre **Calm & Study** fue sugerido por el asistente de IA mientras explorábamos nombres; yo decidí conservarlo, también por su representación femenina en un contexto donde las mujeres suelen ser infravaloradas. La plataforma recibe a personas de todos los géneros.

## Decisiones que tomé

Aprendizaje gratuito, respetuoso y accesible; fuentes públicas verificables; incertidumbre transparente; revisión humana antes de publicar; modos tranquilo y lúdico con el mismo estándar de evidencia; temas educativos y constructivos; prohibición de contenido explícito, ilegal, abusivo o que promueva desinformación y ataques; privacidad y bienestar; MIT para el código y CC BY 4.0 para textos originales, respetando licencias de terceros.

## Recomendaciones técnicas

React, Vite, pnpm, Cloudflare Pages/Functions y D1, Docker Compose, nombres de workflows, límites entre paquetes y comprobaciones automatizadas son medios de implementación. Puedo revisarlos si otra opción conserva el bajo coste, la seguridad, la claridad y los compromisos anteriores.

El repositorio de origen contiene commits anteriores y datos de autoría. Un repositorio de destino limpio evita copiar ese historial literalmente; este resumen conserva el contexto sin volver a publicar datos personales en documentos nuevos. Los próximos commits deben usar el seudónimo público y, si está disponible, una dirección GitHub noreply.
