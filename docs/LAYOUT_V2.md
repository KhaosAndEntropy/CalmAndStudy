# Direção visual v2

A branch `v2` apresenta uma alternativa visual para a Calm & Study, mantendo o catálogo, a pesquisa de fontes e os fluxos existentes.

## Ideia de design

- Linguagem editorial inspirada em cadernos de descoberta: verde profundo, papel quente, acentos de argila e amarelo suave.
- Títulos serifados para dar personalidade e texto de leitura maior, com linhas mais arejadas.
- Ilustrações vetoriais próprias, formas orbitais e detalhes assimétricos; sem fotografias externas nem fontes de terceiros.
- Cards com o assunto e a ilustração em primeiro plano, mantendo os sinais de procedência visíveis.
- Navegação lateral no desktop e menu deslizante funcional no celular.
- Respeito à configuração de movimento reduzido do sistema e foco de teclado visível.
- As cinco paletas, três layouts e controles tipográficos existentes continuam disponíveis.
- A versão mobile usa o mesmo site responsivo instalável como PWA.

O layout preserva os rótulos de conteúdo demonstrativo e de índices ilustrativos. A camada visual não eleva a confiabilidade dos artigos nem substitui revisão editorial.

## Prévia local

Na raiz do monorepo:

```sh
pnpm install
pnpm dev
```

O Vite inicia a web em `http://localhost:4173`. Para comparar com a versão anterior, troque para a branch `main`; para continuar a v2, use a branch `v2`.
